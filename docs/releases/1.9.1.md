# ServiceTag 1.9.1

ServiceTag 1.9.1 (version code 24) is a fix release for one thing: an asset's Home Assistant season link can now be changed and removed on the phone, and the Developer API and MCP can link, change, stop, resume, force and unlink it. It installs in place over 1.9.0. The database and backups do not change.

## On the phone (#129)

On an asset's season card, once the asset is linked to a Home Assistant helper, there are two new buttons beside Stop syncing and Resume syncing:

- **Change helper** points the link at another on/off helper (`input_boolean`) of the same Home Assistant. It uses the same sheet as Link to Home Assistant, with the Choose entity list, and it asks for a fresh check of the new helper.
- **Remove link** asks first ("Remove the link to input_boolean.example_heater_in_season? This asset stops following it and keeps its current season and history. Your Home Assistant connection and other links stay."), and deletes the link only when you confirm.

Both are hidden on an asset that is held (transferred out).

Remove link keeps the asset's current season and its season history. It deletes only this asset's link and the record of its last change. The Home Assistant connection, its token and every other link stay as they were.

Sync now and the connection stay the phone's alone.

## Developer API & MCP

`POST /v1/assets/{id}/season-sync` now takes one action per call: LINK, CHANGE_ENTITY, STOP, RESUME, SET_MODE and UNLINK. The answer is the `GET`'s shape after the write, plus `switchedFrom`.

- LINK and CHANGE_ENTITY need `confirmEntityId` equal to `entityId`. UNLINK needs `confirmUnlink` true. A missing or wrong confirmation is refused before anything is written.
- Three new error codes: `SEASON_SYNC_REFUSED` (409, with the reason), `SEASON_SYNC_NOT_LINKED` (409) and `SEASON_SYNC_CONFIRMATION_REQUIRED` (422, naming the key).
- The MCP server has six new tools: `link_season_sync`, `change_season_sync_entity`, `stop_season_sync`, `resume_season_sync`, `set_season_sync_mode` and `unlink_season_sync`. It now registers 110 tools.
- No answer carries the address, the home Wi-Fi's name or the token, and no route reaches the sync now, the connection or Forget.

## Upgrading and compatibility

- 1.9.1 installs in place over 1.9.0, and your data stays. Room schema 22 and backup format 21 are unchanged, so an export or Transfer Pack moves both ways between 1.9.0 and 1.9.1.
- The six new MCP tools sent to a 1.9.0 phone get 404 `not_found`, and nothing is written. The tools do not check the phone's version first.

## Known limits

- Removing a link and at once linking the same helper again can let a check that was already under way count for the new link. It is a real reading of that helper, and the new link's own check follows it.
- The nine non-English translations of the three new strings (the Change helper button, the Remove link question, and the sentence the setup sheet shows when it changes a helper) were written without a native speaker's review.

The Developer API's contracts are in [`docs/api/v1.md`](../api/v1.md).
